# Linear Algebra RAG Bot

An offline, single-file Linear Algebra tutor built on Retrieval-Augmented Generation (BM25 + TF-IDF hybrid retrieval over 54 topic chunks) with a step-by-step matrix and vector calculator, photo-based questions (OCR), follow-up questions, practice questions, and the option to add your own notes to the knowledge base.

Open `index.html` in a browser — no server needed. OCR and notes (PDF/DOCX) load their libraries from a CDN on first use.
